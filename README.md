# Blue Is The Colour — Chelsea & Cole Palmer

A responsive, fan-made website celebrating Chelsea FC and Cole Palmer.

## Features
- Chelsea-inspired blue and gold design
- Chelsea club introduction and official links
- Cole Palmer profile highlights
- Embedded YouTube video: **COLE PALMER RAP 🧊** by Z dotss
- Responsive layout for mobile, tablet and desktop

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, then save.

When GitHub Pages is enabled, the site should be available at:
https://lukakrivosic100-finance.github.io/aarons-website/
